# Aquarium support and privacy site

The public support and privacy site for **Aquarium for Mac**, published at
<https://gadgetmanuk.github.io/Aquarium/> via GitHub Pages.

- Overview: <https://gadgetmanuk.github.io/Aquarium/>
- Support: <https://gadgetmanuk.github.io/Aquarium/support.html>
- Privacy policy: <https://gadgetmanuk.github.io/Aquarium/privacy.html>

The site is a dependency-free static HTML/CSS site under `site/`, deployed by
the GitHub Actions workflow in `.github/workflows/pages.yml`, which runs
`scripts/test-support-site.sh` before every deploy.

This repository contains only the public site — the Aquarium application
source lives in a separate, private repository.
