Support

Aquarium doesn't collect any usage data, so the best way to get help is to tell us directly. Support is handled through GitHub Issues — there's no support email address.

Report a problem or ask a question

Open an issue on GitHub: github.com/GadgetManUk/Aquarium/issues. You'll need a free GitHub account to post, but you can read existing issues without one.

What to include

These details help us reproduce and fix problems quickly:

macOS version
Apple menu → About This Mac
Mac model
Apple menu → About This Mac (e.g. "MacBook Pro 16-inch, 2023" or "Mac Studio")
Display count
The number of displays connected to your Mac, and how many Aquarium is showing on
Aquarium version
Shown in the About Aquarium window as "Version X.Y.Z (build)"

Where is About Aquarium?

Open the About Aquarium window from either place:

  • The About button in the main Aquarium controls panel.
  • The About Aquarium… item in the Aquarium application menu.

About Aquarium shows the app version and build number, whether you have the Free edition or Aquarium Pro, and links to Support, the Privacy Policy, and Restore Purchases.

Restore Purchases

If you've bought Aquarium Pro before — on this Mac or another one signed into the same Apple Account — you can restore it without paying again.

From the About Aquarium window

  1. Open About Aquarium (see above).
  2. Click Restore Purchases.
  3. Wait for "Checking the App Store…" to finish. You'll see "Purchases restored." if it succeeds.

From the upgrade sheet

  1. Try to select a Pro-only display count, background, fish, or Ultra quality to open the Aquarium Pro upgrade sheet.
  2. Click Restore Purchases in that sheet.
Signed in matters. Restore Purchases only finds purchases made with the Apple Account currently signed in on this Mac (Apple menu → System Settings → Apple Account). If you bought Aquarium Pro under a different Apple Account, sign in with that account first.

Troubleshooting

I can't select two or three displays

Two things need to be true: Aquarium Pro must be unlocked, and enough displays need to be connected. Free accounts are limited to one active display regardless of how many are connected. If you already have Aquarium Pro, connect the extra displays first — the display count selector only enables counts up to the number currently connected.

A display disconnected or was reconnected

If a display disconnects, Aquarium temporarily reduces the active display count. Your preference isn't lost — when enough displays reconnect, Aquarium automatically restores your chosen count without any action from you.

Performance and rendering quality

Aquarium offers Gentle, Balanced, and Vivid rendering quality to everyone, and Ultra quality with Aquarium Pro. Ultra targets native display resolution at up to 8K and is more demanding on your Mac's GPU. If you notice reduced performance on Ultra, especially across multiple displays, try Vivid or Balanced instead.

Some fish aren't showing up

Check each species' enable switch and quantity in the fish selection panel — a species set to zero, or switched off, won't appear. Some swimming varieties and backgrounds require Aquarium Pro; free accounts see clownfish, blue tang, and yellow tang only.

How do I get back from interactive mode?

Press Esc at any time while in interactive mode to return to desktop mode.

How do I pause the aquarium?

Use the Pause control in the main controls panel. Aquarium shows "OCEAN PAUSED" while paused, and you can resume from the same control.

My purchase says "pending" or mentions Ask to Buy

If a purchase was made with Ask to Buy (for example, by a family member), it can remain pending until approved. Aquarium shows a pending state and won't unlock Pro features until the purchase is approved through the Apple Account that requested it.

Refunds

All Aquarium purchases are processed by Apple. Refunds are handled by Apple, not by us — request one at reportaproblem.apple.com.
